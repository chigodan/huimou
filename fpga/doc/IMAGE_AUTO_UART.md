# AWB 开关与摄像头自动曝光

默认AWB、AE开启，显示亮度偏移为0。本说明介绍图像自动调节与电脑控制台的接口；图像设置独立于目标检测和舵机控制。

## 原理与参数

AWB沿用共享除法器与帧级增益。关闭时在帧边界使用Q16单位增益，后台继续计算，重新开启使用已准备的增益。四像素并行、原像素延迟配置和限幅保留。开关不旁路既有空间颜色校正。

AE从白平衡前的去马赛克RGB取样，每16个有效四像素拍取第一个像素，约1/64像素。亮度近似(R+2G+B)/4；完整1280×720帧有14400个样本。24位累加、16位计数与24拍迭代除法产生整数均值，少于256个样本不发布。统计旁路工作，不暂停视频。

| 参数 | 当前值 |
|---|---|
| 控制时钟 | 约23.809524 MHz，摄像头配置域 |
| 目标与死区 | 128，120～136内不反复写入 |
| 曝光码范围 | 8～1991，当前720p60模式 |
| 增益档位 | 16～176，通过SC520GainTbl转换 |
| 初始化曝光码/增益档 | 1991/144，与原配置基线一致 |
| 写入后等待 | 丢弃后续3次帧统计再决策 |
| 无统计超时 | 250 ms，停止调节 |
| 写入握手超时 | 500 ms，故障并停止继续写入 |

偏暗先增曝光，达到上限再增增益；偏亮先减增益，再缩短曝光。曝光步长随误差与当前值变化，最小1。关闭AE保持最近参数，不恢复固定默认值；上电仍建立已确认的初始参数。

曝光/增益载荷在I²C事务期间保持，等待O_ae_cfg_done先拉低再拉高。沿用uicfgcs520、uics520regAE、SC520GainTbl及uii2c，实际写入0x3812组保持以及曝光、模拟/数字增益寄存器。报告的是最近写入确认值，传感器效果需再等待稳定。曝光码不是毫秒，增益档不是百分比或直接倍率。I²C故障/超时后需排查并复位。

显示亮度保留-128～+127和原0x11/0x12命令，只在HDMI后级调整，不参与测光或目标检测。“亮度归零”仅恢复显示偏移0。

## 界面

HDMI顶层设置IMAGE_OSD_ENABLE=1，保留MODE/FPS/LATENCY/VIDEO，ID HEX行换为AWB/AE开关，并增加AE状态行。帧编号监测和原STATUS仍保留。独立模块默认IMAGE_OSD_ENABLE=0兼容原测试。

AE状态为WAIT、ADJUSTING、STABLE、DARK LIMIT、BRIGHT LIMIT、HOLD / OFF、I2C ERROR。达到参数边界仍偏暗或偏亮时报告LIMIT。

电脑增加AWB、AE及“应用图像设置”，显示实际开关、测光/目标、曝光码、增益档与红蓝增益。原帧/结果序号和样本年龄的UI位置改用于图像参数，协议字段不删。未提交的复选框选择不被轮询覆盖。小窗口约1024×740。

## UART扩展

保留AA55、版本1、CRC-16/CCITT-FALSE、旧命令和28字节STATUS。新增PING能力bit5(0x0020)，实际自动视频顶层能力为0x003B。旧固件无此位时禁用新控件并不发扩展查询。

0x13 SET_IMAGE_AUTO / 0x93：请求1字节，bit0 AWB、bit1 AE，只允许0～3。成功回复[RESULT=0, flags]。开关经ISP帧边界与曝光域统计事件应用，后续事件确认下游已看到设置后回复。开关确认不代表曝光已收敛；状态另行查询。与算法/亮度提交互斥，400 ms超时回滚请求。保留重发、冲突、BUSY及迟到确认规则，不改变算法控制权。

0x14 GET_IMAGE_AUTO / 0x94：无请求载荷，成功回复16字节，小端。

| 偏移 | 长度 | 含义 |
|---|---|---|
| 0 | 1 | RESULT |
| 1 | 1 | bit0 AWB实际开关；bit1 AE实际开关；bit2测光有效；bit3传感器参数确认；bit4遥测就绪 |
| 2 | 1 | 0等待、1调节、2稳定、3暗场上限、4亮场下限、5关闭保持、6故障 |
| 3 | 1 | 测光0～255 |
| 4 | 1 | 目标，当前128 |
| 5 | 1 | 已确认增益档 |
| 6 | 2 | 已确认曝光码 |
| 8 | 4 | 红增益Q16，低20位使用 |
| 12 | 4 | 蓝增益Q16，低20位使用 |

多位状态通过保持载荷的请求/确认邮箱跨域。曝光参数组与白平衡参数组分别一致，不承诺来自同一帧。电脑验证回复、长度、状态及增益范围，并考虑请求耗时，不把请求回显当成功。

## 实板演示

1. 自行实现当前工程并下载新bit，运行电脑端uart_step3_ui/Launch.cmd。
2. 显示亮度归零，观察默认AWB/AE开启及参数回读。
3. 曝光稳定后关闭AE，用白纸/彩色物体切换AWB，对比颜色和红蓝增益。
4. 关闭AE并改变照明，再开启AE，观察画面、测光、曝光和增益逐步变化；检查限幅提示。
5. 覆盖六模式、跟踪、丢失和退出复位，验证现有固定阈值在变化后的画面中仍适用。

本次未运行TD、生成bit或打开实板串口。行为仿真和UI模型不能替代真实摄像头测量，收敛速度、灯光闪烁、颜色、跟踪及资源/时序需同版本上板与实现报告确认。没有新增直方图均衡或工频防闪烁算法。
